核心体验

按手表逻辑工作，而不是再做一个窗口

MaciWatch 把交互半径压缩到一块手表里：看时间、开 App、控音乐，都不必把焦点从当前工作移开。

表冠与侧键

点击表冠进入 Honeycomb Home，拖动调节音量；侧键逐级返回，时钟层按下即可退出。

桌面级悬浮

置顶、贴桌面、点击穿透、拖拽记忆、全空间显示与 Peekaboo 隐藏，一组模式覆盖多种工作流。

轻量 App 启动器

12 个内建轻应用收进蜂窝界面，天气、提醒、音乐与系统控制不需要占据一个完整窗口。

音乐控制中心

队列、播放、音量与封面集中显示；本地与多平台音乐架构保持统一的使用路径。

本机优先

状态与偏好保存在本机；没有账号系统，也没有广告跟踪或第三方分析脚本。

原生性能

SwiftUI、AVPlayer 与系统窗口能力直接协作，避免浏览器包装带来的输入延迟和电量负担。

操作路径

从时钟到音乐，只需要两次手表动作

启动永远回到时钟。需要更多能力时，表冠进入 Home；侧键按路径返回。交互少一层，注意力就少一次跳跃。

  1. 表冠点击打开 Honeycomb Home
  2. 选择音乐进入平台 Hub 与播放队列
  3. 表冠拖动调节音量并显示 HUD
  4. 侧键返回播放 → Hub → 时钟

不是。MaciWatch 是付费商业软件，源码与官网项目都不按开源许可授权，也未授权二次分发或转售。

价格什么时候公布？

正式试用版与购买流程完成前，价格暂不公开。你可以通过授权表单获取个人、家庭或团队报价。

支持哪些系统？

基础功能支持 macOS 14+。液态玻璃等新系统能力会在可用时增强，不会成为基础功能的硬性门槛。

音乐功能包含版权吗？

不包含。应用只提供播放与控制入口，用户需自行保证账号、内容与当地法规授权。

它与 Apple Watch 有关系吗？

没有官方关系。Apple、Apple Watch 与 macOS 是 Apple Inc. 的商标，MaciWatch 是独立软件。
