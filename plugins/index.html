Plugins

一份 JSON，
手表上多一个轻应用

MaciWatch 插件是纯声明式清单：元信息、页面组件、设置与 HTTP 动作写进一个 JSON 文件，导入即用，不需要写任何代码。

声明式 JSON HTTP + JSONPath 14 种内容组件 状态本地持久化 {{模板}} 变量 AI 代写提示词

快速开始

三步跑起第一个插件

01

生成清单

复制下方「AI 代写提示词」粘给任意 AI，补一句需求直接生成；或用在线生成器配置导出 <id>.json，也可以下载示例插件改字段。

02

导入 MaciWatch

表冠点击打开蜂窝 → 插件管理 → 右上角导入：选择 JSON 文件，或粘贴清单文本。同 id 重复导入会覆盖重装。

03

蜂窝里打开

插件出现在 Honeycomb 蜂窝中，点按即进入；打开时自动执行首个 HTTP 动作拉取数据，也可配置定时刷新。

AI Prompt

让 AI 帮你写插件

不会写 JSON 也没关系：把下面这段格式提示词整段复制给任何 AI（ChatGPT、Claude、GLM……），末尾补一句你的需求，它就能产出可直接导入 MaciWatch 的插件清单。

  1. 复制提示词
  2. 粘给 AI，写下你的需求
  3. 把生成的 JSON 导入 MaciWatch

1. 顶层字段

            
一个插件是一份 JSON 对象，包含元信息、页面、动作、初始状态与刷新策略：

            

              

                
字段类型必填说明

                
                  
idString是唯一标识。字母/数字开头，仅限 A-Z a-z 0-9 . _ -，≤ 100 字符；建议反向域名，如 com.example.stock

                  
nameString是蜂窝与页面标题的显示名

                  
versionInt是整数版本号，从 1 开始

                  
iconString是SF Symbol 名称；导入时逐个校验，非法即拒绝

                  
colors[String]否蜂窝图标渐变，两个 hex 色；缺省灰色。支持 #RGB / #RRGGBB / #RRGGBBAA

                  
backgroundObject否页面背景：solid / gradient / image；缺省用 App 默认背景

                  
stateObject否初始状态键值（字符串 / 数字 / 布尔），修改后持久化到本机

                  
refreshIntervalDouble否定时刷新秒数，≥ 5 生效；缺省不定时

                  
loadOnStartBool否打开插件即执行默认刷新动作 · 缺省 true；设 false 后仅手动触发

                  
pagesObject是页面表，键为页面 id；main 是入口页，其余为 navigate 子页

                  
actionsObject是动作表，键为动作 id，供按钮 / 头部控件 / 自动刷新引用

                
              

            

          


          

            
2. 页面与头部

            
每个页面（PluginPage）由四部分组成：头部、内容组件数组、可选设置区、可选底部按钮。整页按「头 / 主区 / 附加区 / 底钮」滚动布局渲染。

            

              

                
字段类型说明

                
                  
headerObjecttitle（必填）、icon（可选）、trailing[]（可选，右侧控件）

                  
bodyArray内容组件，见下一节；可为空

                  
settingsArray设置区控件，改动即写回 state；可省略

                  
bottomArray底部按钮；可省略

                  
fitBooltrue = 一屏完整（FitPage）：中区不滚动、内容自适应——文字自动缩放、圆环 / 二维码占满中区；缺省 false 走溢出滚动 + 底部呼吸折叠箭头

                  
nativeString原生页标记（当前白名单 music）：整页直接渲染内置音乐 App（扫码登录 / 四宫格 / 播放器），界面与行为和原生一致，插件只做入口

                
              

            

            
头部右侧控件 trailing 有三种：

            

              

                
type字段行为

                
                  
buttonicon、action点按执行动作；命中默认刷新动作时显示加载态

                  
togglebind、iconOn、iconOff开关绑定 state 键，随值切换图标

                  
textbind只读显示 state 值

                
              

            

          


          

            
3. 内容组件

            
body 是组件数组，每个组件以 type 区分。文本取值方式：value（字面量，支持 {{key}} 模板）或 bind（读 state；np. 前缀实时读内置播放器）二选一。

            

              

                
type字段说明

                
                  
textvalue / bind、style、color文本。style：normal · hero（大字）· caption（小字）；color：default · accent · warning · gradient（渐变）

                  
metricvalue / bind、unit、style、animated大数值（汇率 / 计数）。unit 追加单位；style 缺省 hero；animated: true 数字滚动动画 + 等宽数字

                  
iconvalue大号 SF Symbol

                  
listbind、titleKey、subtitleKey、valueKey、emptyText、onTap、progressKey、progressMax读 state 数组渲染列表行。onTap：{page, prefix} 点击项后把该元素字段写入 prefix.*（另附 _index / _total / posFrac）并跳页；progressKey 给每行加用量条（progressMax 缺省 100 按百分比）

                  
progressvalue / bind、label、detail、showPercent、max、thresholds进度条，取值 0–1。带 label / detail / thresholds 时渲染为 AI 用量风格（标签 + 百分比行 / 三色胶囊条 / 说明行）；thresholds: {warning, critical} 越限变橙 / 红

                  
ringvalue / bind、label、showPercent、max、thresholdsAI 用量主页大圆环风格：trim 圆环 + 中心百分比 / 标签；fit 页占满中区，滚动页固定尺寸

                  
statsitems[]三列统计格（天气页风格）：每格 icon + value / bind + caption

                  
sparklinebind迷你折线：读数字数组，归一化绘制 + 渐变填充

                  
countdownvalue / bind、label倒计时：目标时刻支持 ISO8601 或 unix 秒 / 毫秒，每秒自驱动

                  
tagsbind 或 values[]胶囊标签组：读字符串数组（或字面量），自适应网格换行

                  
imagevalue / bind远程图片：下载后缓存到本地（plugin-assets），封面风圆角 + 高光描边

                  
qrvalue / bind二维码：fit 页占满中区，滚动页固定尺寸

                  
spinnerbind加载指示：bind 读布尔（np.isLoading 现成可绑），true 时显示；缺省常显

                  
divider—分隔线

                
              

            

          


          

            
4. 设置区

            
设置区常驻在附加区，控件通过 bind 直接读写 state 键，改动立即持久化；HTTP 动作的 {{key}} 模板会读到最新值。

            

              

                
type字段说明

                
                  
pickerlabel、bind、options[]下拉单选，选项为字符串数组

                  
stepperlabel、bind、min · 0、max · 100、step · 1数字步进器

                  
togglelabel、bind布尔开关

                
              

            

          


          

            
5. 底部按钮

            

              

                
字段说明

                
                  
label / icon文字与 SF Symbol，至少给一个

                  
action点按执行的动作 id

                  
styleprimary · 实心强调色；plain · 玻璃质感；danger · 红（危险操作语义）

                  
confirmtrue = 两击确认：第一击变红 3 秒，再击才执行——App 内禁弹窗的防误触语义

                
              

            

          


          

            
6. 动作

            

              

                
type字段行为

                
                  
httpmethod · GET、url、headers{}、body、extract{}发请求（15 秒超时）；url / headers / body 支持 {{key}} 模板；extract 把响应按 JSONPath 写入 state

                  
setvalues{}就地写入若干 state 键值

                  
copytext渲染模板后复制到剪贴板

                  
open-urlurl渲染模板后用系统浏览器打开 · 仅 http/https

                  
navigatepage页内导航到 pages 中的另一页，头部出现返回箭头

                  
mediacommand控制内置播放器：toggle（播放 / 暂停）· next · prev；对任何已装载音源队列（本地 / 网易云 / 酷狗……）通用

                  
appprovider打开原生音源页：local · netease · qq · kugou（后三者为社区版能力，App Store 构建优雅降级为提示）

                
              

            

            
JSONPath：extract 的值是点路径加数组下标，例如 $.rates.CNY、$.list[1].n；取不到时该键写入 null。

          


          

            
7. 运行时语义

            
    
              
  • 默认刷新动作：第一个 http 动作（没有则第一个动作）。打开插件且 loadOnStart ≠ false 时执行一次；refreshInterval ≥ 5 秒则按周期重复。
    • 
              
  • 模板变量：{{key}} 会替换成 state 当前值（数字、布尔直接转文字）；state 中不存在的键原样保留，方便分步调试。
    • 
              
  • 播放器数据源 np.*：bind 以 np. 开头时绕过插件 state，实时读内置播放器（np.title、np.artist、np.playlist、np.cover、np.isPlaying、np.isLoading、np.index、np.total、np.currentTime、np.duration、np.progress、np.timeText）；只读——set / extract / 设置区 / 列表 onTap 前缀均不可写入。
    • 
              
  • 布局语义：缺省页溢出滚动（底部呼吸折叠箭头提示下方内容，到底变向上）；fit: true 强制一屏完整，中区内容自适应。
    • 
              
  • 状态持久化：state 首次修改后写入本机 UserDefaults（键 plugin.state.<id>），重启 App 保留；插件管理里可重置回初始值。
    • 
              
  • 反馈：请求进行中显示玻璃加载态；失败在头部下方给出提示文案，成功后自动清除。
    • 
            

          


          

            
8. 安装与管理

            
    
              
  • 存放位置：~/Library/Application Support/MaciWatch/plugins/<id>.json，也可以手动放文件，插件管理会自动扫描。
    • 
              
  • 导入方式：插件管理 → 右上角导入 → 选择 JSON 文件，或粘贴清单文本；文件名不影响 id，落盘以清单内 id 为准。
    • 
              
  • 覆盖与卸载：同 id 重复导入即覆盖重装；插件管理支持删除与在蜂窝中隐藏（显隐只记「隐藏」名单）。
    • 
              
  • 内置示例：首次启动自动种入「汇率」与「一言」两个示例插件，可随意修改或删除。
    • 
              
  • 热心网友分享：本页下方的社区示例可直接下载导入；欢迎把你的插件 JSON 以代码片段形式分享出来，优秀作品会收录到这里。
    • 
            

          


          

            
9. 安全与校验

            
    
              
  • id 白名单：仅字母/数字开头 + A-Z a-z 0-9 . _ -，长度 ≤ 100，拒绝路径穿越（如 ../evil）与纯符号。
    • 
              
  • 仅限 Web 协议：HTTP 与 open-url 只放行 http / https，file:// 等本地协议一律拒绝。
    • 
              
  • 图标校验：清单内全部 SF Symbol 引用（含头部、trailing、body、底钮）都必须在当前系统符号集内，否则拒绝导入。
    • 
              
  • 数据边界：state 只存本机，不上传；请求超时 15 秒，失败不影响其他插件。
    •
