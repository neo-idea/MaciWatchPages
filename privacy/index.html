隐私政策

本政策说明 MaciWatch 官网和当前应用版本如何处理信息，以及你可以行使哪些权利。

1. 隐私概要

当前设计遵循本机优先原则：MaciWatch 不要求网站账号，不内置广告，不使用第三方网站分析脚本，也不为个性化广告建立用户画像。

应用偏好、表盘设置和本地播放信息主要保存在你的 Mac 上。开发者通常不会接收这些数据。

2. 官网信息

网站由 GitHub Pages 及其内容分发基础设施提供服务。你访问页面时，浏览器会自动向服务器发送技术信息，例如 IP 地址、请求时间、浏览器类型、语言和Referer。

这些信息由托管服务用于安全、防滥用和页面分发。本站当前不加载第三方分析脚本，也不通过表单数据库收集邮箱。

内测表单会打开你的邮件客户端。只有你主动发送邮件后，邮件内容才会到达我们。

3. 应用数据

应用会在本机保存必要配置，例如窗口位置、表盘选择、音乐偏好、显示模式和授权状态。

本地音乐功能会读取你明确选择的内容或目录，用于播放、队列和封面显示。除非你主动导出、截图或发送问题报告，这些信息不会发送给开发者。

4. 系统权限

macOS 可能会为媒体播放、文件访问、通知或其他能力请求权限。权限由系统授予，你可以随时在系统设置中撤回。

撤回权限可能导致对应功能不可用，但不会影响软件的基础时间显示。

5. 第三方音乐服务

当你连接第三方音乐平台时，登录、鉴权、歌单、推荐、播放和计费等处理发生在你、该平台与其接口之间。

平台如何处理账号和数据适用其隐私政策。MaciWatch 只在实现功能所需的范围内处理相关接口返回的数据，例如歌单名称、曲目信息、封面或播放状态。

6. 邮件沟通

如果你通过邮件联系我们，我们会使用你的邮箱、邮件内容及相关记录来回复问题、处理授权请求或提供支持。

我们不会出售邮箱，也不会未经同意把你加入营销群发列表。

7. 保留与删除

邮件沟通和授权记录仅在实现用途、履行义务或解决争议所需的期间保留。

本机应用数据存储在你的设备上。你可以通过卸载应用或删除相关配置来移除这些数据；具体系统路径可能因版本和 macOS 设置而不同。

8. 你的权利

根据所在地区法律，你可能有权访问、更正、删除或限制处理个人数据，也可以对某些处理提出反对或向监管机构投诉。

如果适用法律要求识别身份，我们会说明必要信息，并避免收集额外数据。

9. 安全

官网通过 HTTPS 提供服务。我们会使用合理的技术和组织措施保护有限的数据。

没有任何互联网传输或软件可以保证绝对安全。请及时更新系统和应用版本。

10. 未成年人

MaciWatch 不是面向儿童设计的产品。如果认为未成年人向我们发送了个人数据，请联系我们，我们会根据适用法律删除。

11. 政策变更

产品功能、托管服务或法律要求变化时，我们可能更新本政策，并更新页面日期。

如变更涉及新的数据处理方式或重大影响，会在官网或应用内提供适当提示。

12. 联系

隐私问题请联系：license@zpad.app
